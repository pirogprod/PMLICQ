# Обновление репозитория GitHub

Этот ZIP основан на PMLICQ ARS RX FIX9 и содержит исходники четырёх деревьев: `normal/0.96.7`, `normal/0.96.8`, `windows-xp-x86/0.96.7`, `windows-xp-x86/0.96.8`.

1. Сделайте резервную ветку через GitHub Desktop и сохраните текущий стабильный ZIP.
2. Распакуйте этот архив отдельно; скопируйте **содержимое** `PMLICQ/` в корень локально клонированного репозитория, не удаляя `.git`.
3. Сверьте изменения в GitHub Desktop, особенно если в репозитории есть прежняя структура `sources/`, и не удаляйте нужные файлы без проверки.
4. Выполните commit и Push origin, предпочтительно сначала в экспериментальную ветку `ars-file-transfer-beta`.
5. Не объявляйте код стабильным до проверки x86/x64 на Miranda NG 0.96.7 и 0.96.8.

**Только исходники и документация; готовые DLL не включены.**

Добавлены изменения Client ID (ICQ 5.1/6, QIP 2012), значки клиентов и x64-оптимизация; при этом сама передача `Miranda NG PMLICQ` сохранена. Перед публикацией проверьте лицензирование сторонних изображений и соберите/протестируйте нужные версии на своей системе.

## Обновление 22.11.2026 — значки клиентов вынесены в Fingerprint

- **PMLICQ** остаётся отдельным протокольным модулем и продолжает распознавать клиентское ПО контактов по входящим capabilities, сохраняя результат в поле `MirVer`. Распознавание ICQ 5.1, ICQ 6, QIP 2012, QIP 2005, Jimm и прочих известных клиентов сохранено; ранее исправленные входящие сигнатуры не изменялись при переносе значков.
- Из веток PMLICQ **0.96.7 и 0.96.8 (x64 и x86/Windows XP)** удалены только собственные клиентские ExtraIcons (`PMLICQ_Client`) и их ресурсные иконки. Отдельные X-статусы `PMLICQ_XStatus` не удалялись.
- За отображение значков клиента теперь отвечает **внешний Fingerprint**, используя `MirVer`, `fingerprint.json` и набор пользовательских ICO. Для QIP 2005a и `QIP ver. 2005a`, ICQ 5.1, ICQ 6, QIP 2012 и остальных клиентов разработан отдельный набор правил сопоставления.
- Добавлена маска `*magent*` для обозначений Mail.Ru Agent (`client="magent" version="6.3" build="8065"` и других версий/вариантов написания); значок — `cli_mailru.ico`. Это правило применяется в конфигурации **Fingerprint**, а не в исходниках PMLICQ.
- В отдельном пакете Fingerprint подготовлены расширенные `Fp_icons.dll` для x64 и x86 и дополнительные ICO. **Эти DLL не являются зависимостями PMLICQ и в настоящий репозиторий исходников не включаются.** Подробности: `FINGERPRINT-INTEGRATION-RU.md`.
- Сохранены прежние особенности стабильных веток: оптимизация обновления списка контактов для x64 и настройки сборки x86 с поддержкой XP на уровне проекта. Сетевой протокол, исходящая идентификация `Miranda NG PMLICQ`, сообщения, файлы и X-статусы в этом обновлении не изменялись.

**Ограничения проверки:** архив с исходниками сопоставлен с предыдущими версиями; запуск PMLICQ и отображение клиентских иконок в реальной Miranda NG на всех платформах не проводились. Пользовательские правила Fingerprint следует устанавливать отдельно, сохраняя резервную копию своего `fingerprint.json`.
