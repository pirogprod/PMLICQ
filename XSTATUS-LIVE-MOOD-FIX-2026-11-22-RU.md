# PMLICQ — обновление чужого X-статуса без переподключения (исходники, TEST)

## Симптом
Собственный X-статус отображается после предыдущего исправления. Если другой OSCAR-клиент устанавливает, меняет или снимает X-статус во время активного соединения, значок в PMLICQ не обновляется до переподключения.

## Причина в исходниках
`HandleUserOnline()` ранее определял X-статус только по 16-байтным GUID из TLV `0x000D` (capabilities). Некоторые ICQ/Jimm-клиенты передают изменения X-статуса через TLV `0x001D`, запись `0x000E` (текстовый идентификатор вида `0icqmood23`), не повторяя старые capabilities. Обработка TLV `0x001D` в PMLICQ ранее извлекала только текст (`0x0002`), игнорируя mood (`0x000E`).

## Исправление
- Добавлен ограниченный декодер mood `0icqmood...` и сопоставление **31 mood-номера** с существующими 35 иконками по известным соответствиям GUID. Это только сопоставление; клиентские идентификаторы/Fingerprint не менялись.
- При входящем SNAC(03,0B) с `0x001D/0x000E` значок контакта устанавливается/меняется немедленно через точечный `KicqRefreshSingleXStatus()`.
- Пустая запись mood (`0x000E`, длина 0) снимает значок. Отсутствие записи mood не интерпретируется как сброс, а некорректный/неизвестный код не затирает действующий статус.
- Короткие capabilities TLV `0x0019` больше не обнуляют X-статус, поскольку сами по себе не описывают X-статус. Полная запись TLV `0x000D` по-прежнему обрабатывается отдельно.
- Все действия с ExtraIcon выполняются вне блокировки ростера, без массового `ExtraIcon_SetAll`.
- Отладочные/транспортные участки PMLICQ не менялись, собственные X-статусы из прежней версии сохранены.

## Ветки
`normal/0.96.7`, `normal/0.96.8`, `windows-xp-x86/0.96.7`, `windows-xp-x86/0.96.8` — изменён только `KICQ/src/server.cpp` (кроме дополнения документации).

## Тестирование
Ограниченный декодер с исходным C++ кодом проверен компилятором g++ (C++17) на установку, смену, пустую mood-запись, отсутствие mood, неизвестный код и повреждённую длину. DLL под Windows не собиралась, на сервере OSCAR не тестировалась. Скрипт теста `tests/test_live_mood.py` можно запускать из корня архива (требуется Python 3 и g++).

В клиенте проверьте: два подключённых разных UIN → на другом клиенте установить X-статус → поменять → снять → проверить значок в PMLICQ без выхода из сети. После этого перепроверить собственный X-статус и переключение обычного Online/Away. Если сервер вообще **не отправляет SNAC(03,0B)** при смене mood, клиент не получит уведомление — понадобятся сетевые логи/настройка сервера либо отдельный механизм опроса.

## Примечание о нестандартных mood
Четыре mood-токена (`0icqmood13`, `0icqmood61`, `0icqmood66`, `0icqmood83`) не имеют соответствующего оригинального GUID в текущем наборе 35 ресурсов PMLICQ и намеренно не назначаются случайным картинкам. Неизвестные значения игнорируются безопасно.
