# Fingerprint: внешний показ клиентских значков PMLICQ

Этот документ добавлен к исходникам PMLICQ 22.11.2026. Стабильный механизм **определения** клиентского ПО остаётся в PMLICQ; отображение **значков** передано отдельному плагину Fingerprint.

## Что теперь делает PMLICQ

- При получении присутствия контакта анализирует входящие capabilities.
- Сохраняет определённое название клиента в настройке контакта `<модуль аккаунта>/MirVer`.
- Не регистрирует `PMLICQ_Client` и не загружает клиентские значки; `PMLICQ_XStatus` продолжает работать отдельно.

## Как подключить значки Fingerprint

1. Установите Fingerprint, совместимый с вашей версией и архитектурой Miranda NG.
2. Закройте Miranda и сохраните копию профиля.
3. Из отдельного пакета `Fingerprint_ALL_CLIENTS_ICON_PACK_x86_x64_MRA_MAGENT_FIX.zip` возьмите папку `Miranda/Icons/Fingerprint_Custom`, поместите её в папку Miranda; совместимость путей проверяйте с инструкцией пакета.
4. Разместите или **объедините** `Profile/fingerprint.json` в каталоге профиля Miranda. При существующем файле не заменяйте его без копии: нужно сохранить старые правила, добавив новые. Для удобства используйте скрипт установки из пакета.
5. Перезапустите Miranda и убедитесь, что Fingerprint видит `MirVer` контакта и соответствующий ICO. Если отображается `?`, сначала уточните точное значение `MirVer` через DBEditor++.

**Сопоставления в отдельном пакете:** `QIP 2005a` / `QIP ver. 2005a` → QIP 2005; `ICQ 5.1` → ICQ 5.1; `ICQ 6` → ICQ 6; `QIP 2012` → семейство QIP Infium; `Jimm` → Jimm; `Miranda NG PMLICQ` → Miranda. Правило `*magent*` назначает `cli_mailru.ico` любому описанию с упоминанием magent, включая строку `client="magent" version="6.3" build="8065"`.

**Важно:** `fingerprint.json` и `Fp_icons.dll` принадлежат отдельному пакету Fingerprint, не являются частью сборки PMLICQ. `Fp_icons.dll` для x64 и x86 подбираются строго по архитектуре Miranda NG; сами пользовательские ICO архитектурно независимы. Не размещайте сторонние изображения в публичном репозитории без проверки прав на распространение.

## Исходный код и стабильность

Старые модули PMLICQ и их алгоритмы идентификации не заменялись. Для отключения клиентских значков применены изменения файлов `proto.cpp`, `proto.h`, `server.cpp`, `resource.h`, `res/resource.rc` в каждой из четырёх веток. Исходники XP/x86 и оптимизированного x64 находятся отдельно. Проверка реального запуска и совместимости с SDK/CRT Windows XP требуется на целевой машине.
