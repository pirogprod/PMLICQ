# Исправление значка X-статуса «Злой» (Angry) — 22.11.2026

## Симптом
Все X-статусы у удалённых контактов обновляются в реальном времени, но значок первого статуса «Злой» не отображается.

## Причина
Первый X-статус имеет ID 1; соответствующий значок регистрируется в ExtraIcons первым. Возвращённый `ExtraIcon_AddIcon` индекс изображения может быть равен 0. Код `KicqExtraApply` ошибочно трактовал 0 как отсутствие значка из-за дополнительного булевого условия `g_kicqExtraImages[id - 1] && ...`. В результате единственный первый значок скрывался, хотя ресурс `29100` / `xstatus_01.ico` присутствует и содержит непрозрачные пиксели.

## Минимальное исправление
В четырёх вариантах `KICQ/src/proto.cpp` проверка теперь отвергает только `INVALID_HANDLE_VALUE`, сохраняя 0 как допустимый индекс изображения. Остальные коды ExtraIcons, статусы, OSCAR и Fingerprint не менялись.

## Проверка
Статически проверено: ID=1, GUID `01D8D7EEAC3B492AA58DD3D877E66B92`, иконка `xstatus_01.ico` в каждом дереве и корректная запись в `resource.rc`; визуально иконка не пустая. Проверен дифф и целостность архива. Компиляция DLL под Windows и работа с живым сервером НЕ проверены.

Тест в Miranda: при подключённых клиентах с разных UIN выбрать «Злой» на удалённом клиенте, затем выбрать другой X-статус, затем снова «Злой»; иконка должна появляться без переподключения. Также проверить свой контакт.
