# PMLICQ RX FIX9 — кнопка «Передача завершена, открыть файл»

Изменения только в обработчике входящих файлов `IncomingProgress()` и в завершающих участках потоков приёма в `proto.cpp` (Miranda NG 0.96.7/0.96.8, x86/x64).

**Причина:** в `PROTOFILETRANSFERSTATUS`, передаваемом Miranda через `ACKTYPE_FILE / ACKRESULT_DATA`, не были заполнены `szWorkingDir` и `szCurrentFile`. Из-за этого после успешной передачи интерфейс мог открывать папку по умолчанию вместо принятого файла.

**Исправлено:**
- `PFTS_UNICODE | PFTS_RECEIVING`, `hContact` и номер файла;
- `szWorkingDir.w` — папка, в которую принят файл;
- `szCurrentFile.w` — полный путь к сохранённому файлу;
- при успешном завершении принудительно отправляется финальный `ACKRESULT_DATA` с полным путём до `ACKRESULT_SUCCESS`.

Путь формируется существующей функцией `FileAllow()`; имена входящих файлов, диалоги приёма, исходящий транспорт ARS/OFT2, настройки и остальные функции не менялись.

**Тест:** отправить файл на PMLICQ, принять, дождаться завершения, нажать «Открыть файл». Повторить на x86 и x64, 0.96.7 и 0.96.8. Убедиться, что файл действительно лежит в выбранной папке. Прежде чем заменять установленный DLL, сохранить проверенную копию.

Исходники подготовлены, автоматическая проверка наличия изменений выполнена. Компиляция на Windows с Miranda SDK и реальная передача не выполнялись. Сборка имеет статус TEST.
