# PMLICQ Client Identification v6 — Miranda NG 0.96.7, x64 и x86

Обновлены обе ветки исходников: `normal/0.96.7` (x64) и `windows-xp-x86/0.96.7` (Win32).

## Приём информации о клиентах контактов

- В OSCAR presence нормализуются короткие `TLV 0x0019` capabilities семейства `0946/13xx`, объединяются с полными `TLV 0x000D` и передаются во встроенный детектор из `client_catalog_qip.h`. Повторяющиеся GUID не добавляются.
- Таблица детектора взята из предоставленного вами `client id.zip` (QIP 2005), и находится внутри PMLICQ. Ничего устанавливать в QIP для распознавания контактов САМИМ PMLICQ не требуется.
- Приоритет самоподписанного PMLICQ (`PMLV`) сохранён. Другие клиенты определяются эвристически по таблице; ложные/неполные совпадения возможны.
- Отпечатки `ClientCapsFingerprint`, `ClientShortCapsFingerprint`, `ClientCapsSize`, `ClientShortCapsSize` и имя `MirVer` сохраняются в базе контакта модуля PMLICQ для диагностики.
- X-статусы остаются привязанными к подлинным полным capabilities; нормализованные короткие используются **только** для распознавания клиента.

## Передача клиентской информации серверу

- `SNAC(02,04)` уже передавал собственные `Miranda PMLICQ##`, `PMLV` и текстовый `PMLICQ <version>`.
- В режимах Client ID `PMLICQ` / `Miranda NG` дополнительно отправляется узнаваемый историческими определителями Miranda GUID `MirandaM` с реальной версией запущенного Miranda.exe (по 0.x release-сигнатуре каталога QIP).
- Это повышает совместимость с детекторами, знающими Miranda, но НЕ может заставить любой сторонний клиент показывать произвольное «Miranda NG PMLICQ 0.96.7.0». Для точной подписи внешний клиент должен поддерживать наши сигнатуры `PMLV`/`PMLICQ` или собственное правило.
- Варианты Client ID QIP, Jimm, AIM продолжают влиять на login-пакет; их не следует считать полной имитацией протокольного отпечатка указанного клиента.

## Сборка и проверка

Открыть `normal/0.96.7/KICQ/KICQ.vcxproj` (Release | x64) либо `windows-xp-x86/0.96.7/KICQ/KICQ.vcxproj` (Release | Win32) с соответствующим Miranda SDK. **DLL в этом архиве не собрана и не испытана на Windows**.

На тестовых профилях проверить PMLICQ ↔ PMLICQ, QIP 2005, QIP Infium и Jimm: клиент в поле MirVer, переключение статусов и X-статусов, отправку и приём сообщений. Для сравнения с конкретным QIP использовать сохранённые caps, а также реальный сетевой trace `SNAC(02,04)` и buddy presence: сервер может не распространять все дополнительные private GUID.

## Изменённые файлы

- `.../src/oscar.cpp` — совместимый Miranda fingerprint при публикации.
- `.../src/server.cpp` — объединение полученных full/short capabilities, дополнительная диагностика.
- `.../src/client_catalog_qip.h` — безопасная нормализация коротких capabilities для каталога.

Не менялись пакеты X-статусов, обработчики сообщений, логика подключений и передача файлов.

Проверено локально: тест заголовка каталога через GCC (компиляция и запуск), сверка модификаций обеих веток. Windows-сборка и реальный OSCAR-сервер не проверялись.
