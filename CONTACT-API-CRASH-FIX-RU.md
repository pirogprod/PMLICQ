# Contact API crash fix — Miranda NG 0.96.7 #28846

Отчёт 25.11.2026: Access Violation при вызове db_add_contact → Proto_IsProtocolLoaded из PMLICQ.dll. В 0.96.7 API создания контакта изменился после первого релиза.

* Первоначальный тег v0.96.7: https://github.com/miranda-ng/miranda-ng/blob/v0.96.7/include/m_database.h — db_add_contact(void).
* Установленная сборка #28846: https://github.com/miranda-ng/miranda-ng/blob/495fea6/include/m_database.h — db_add_contact(const char *szModule, int flags = 0), DBAC_NOTINLIST.
* Реализация: https://github.com/miranda-ng/miranda-ng/blob/495fea6/src/mir_core/src/db.cpp.

На старых заголовках сохранена прежняя последовательность. На новых заголовках имя аккаунта передаётся в db_add_contact вместе с флагами, повторная привязка не нужна. Выбор API производится при компиляции по DBAC_NOTINLIST; НЕ определяйте этот макрос вручную. DLL не является универсальной для несовместимых ABI.

## Сборка для установленной Miranda NG 0.96.7 #28846 x64

1. В чистой копии официального репозитория Miranda NG используйте `git checkout 495fea6a61acd926e6613c26f52ba889b788e5df` (при необходимости сначала загрузите эту ревизию).
2. Скопируйте проект из соответствующей x64 ветки этого архива в дерево Miranda NG; интегрируйте в штатный проект/решение. Используйте заголовки и библиотеки именно этой ревизии. Не смешивайте с первоначальным тегом v0.96.7, даже если версия та же.
3. Выберите Release | x64, выполните Clean и Rebuild. Сохраните соответствующий PDB. Не заменяйте библиотеки ядра файлами от другой версии.
4. Сделайте резервную копию профиля и старых DLL, полностью закройте Miranda, замените DLL и проверьте на копии профиля: вход, синхронизацию, создание нового контакта, входящий запрос авторизации и переподключение.

Для XP сохраняются прежние настройки сборки; используйте точную ревизию своего ядра. Ветки 0.96.8 не менялись. Полная сборка MSVC, запуск Windows и тестирование на реальном сервере не выполнялись. Тесты с заглушками SDK проверяют выбор вызова, а не полную ABI-совместимость Miranda или отсутствие всех возможных вылетов.

CONTACT-API-CRASH-FIX.patch — изменения существующих файлов относительно предыдущего полного архива; новые тесты и эта инструкция поставляются в ZIP отдельно.

PMLICQ: используйте normal/0.96.7/KICQ → plugins/KICQ. Изменена только функция CreateContact в двух ветках 0.96.7 и уточнены инструкции/сообщения CMake. AIM, аватары, авторизация и сетевые обработчики не изменены.

Проверки: `python tests/test_contact_api.py` — 6 запусков (два старых/два новых для 0.96.7, два новых для 0.96.8). Identity и avatar_offline_test — 8 запусков (по два на каждую ветку). Все пройдены.
