# PMLICQ — ARS DIAG3 (диагностическая сборка)

Это НЕ подтверждённое исправление зависания. В предыдущей версии ARS FIX2 передача оставалась в состоянии «Ожидание соединения», 0 байт. Диагностика добавлена к существующему файлообмену, остальные функции протокола не менялись.

## Что изменено

В `proto.cpp` и `server.cpp` для x86/x64 на Miranda NG 0.96.7 и 0.96.8 добавлены сообщения Netlib Log с префиксом `ARS DIAG3`. В частности, теперь видно, дошло ли до получателя файловое приглашение (CAP_FILE), прошло ли оно проверку OSCAR TLV/cookie, почему предложение было отклонено до отображения в Miranda, выделен ли слот ARS и получен ли `PROXY_READY`.

**Важно:** реальное соединение с сервером и сборка под Visual Studio здесь не проверены. Это только исследовательское обновление, не готовый стабильный релиз. Сохраняйте прежние рабочие DLL.

## Как собрать и проверить

1. Собрать соответствующий проект Release для Win32 либо x64 в VS 2019 с заголовками нужной версии Miranda.
2. Включить Netlib Log и выполнить одну небольшую отправку между двумя клиентами, желательно обоими PMLICQ DIAG3, после подтверждения приёма.
3. Собрать записи `ARS DIAG3` с обеих сторон, а также ошибки протокола `ICBM` в случае их появления. Удалить из лога пароли, токены, адреса и приватные сообщения перед отправкой.

### Как читать строки

- `ALLOCATE_OK` на отправителе: ARS-прокси выдал слот.
- `OSCAR offer queued` на отправителе, но **нет** `incoming OSCAR file offer` на получателе: проблема доставки/обработки channel-2 ICBM, переходить к OFT2 пока рано.
- `received CAP_FILE ... parse/cookie validation failed`: сервер/клиент прислал другой формат rendezvous либо повреждён cookie.
- `incoming offer rejected before UI`: неверное или неподдерживаемое содержимое файлового приглашения.
- Есть входящее приглашение и `user accepted`, но нет `receiver got READY`: неисправен JOIN к ARS или сам прокси.
- На обеих сторонах `READY`, но 0 байт: проверять OFT2 PROMPT / ACK, включая размер заголовка, контрольную сумму и кодировку имени файла.

Данные стадии соответствуют оригинальной реализации Symnok: https://github.com/Symnok/miranda-kicq/releases/tag/v.0.96.7-1.0.3
