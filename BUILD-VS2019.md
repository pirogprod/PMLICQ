# Сборка PMLICQ в Visual Studio 2019

## Что требуется

- Visual Studio 2019 с компонентом «Разработка классических приложений на C++».
- `MSVC v141` + **Windows XP support (`v141_xp`)**; установленный Windows SDK и библиотеки CRT.
- Дерево исходников/SDK **той же версии Miranda NG**, для которой собирается плагин.

## 0.96.7 и 0.96.8

1. Выберите `sources/0.96.7/KICQ/KICQ.vcxproj` для Miranda NG 0.96.7 **или** `sources/0.96.8/PMLICQ-avatar-ssi-update-delete/KICQ/KICQ.vcxproj` для 0.96.8.
2. Поместите исходники по ожидаемому проектом пути относительно SDK Miranda NG (проект может требовать общих `.props` и `.targets` из исходников Miranda).
3. Откройте проект в Visual Studio 2019. Выберите **Release | Win32**.
4. В свойствах проекта задайте **Platform Toolset = `v141_xp`** и проверьте пути к SDK Miranda, CRT/UCRT. Если нет `stdio.h`, `stdlib.h` или `ctype.h`, исправляйте компоненты MSVC/пути стандартных заголовков, а не код X-статусов.
5. Выполните **Очистить → Пересобрать**, установите получившийся `PMLICQ.dll` в `Plugins` 32-битной Miranda NG и перезапустите клиент.

Для Windows XP нужен XP-совместимый runtime; проверьте импорты готовой DLL и отсутствие Debug-зависимостей вида `MSVCP140D.dll`/`ucrtbased.dll`. `Release | Win32` не означает x64-совместимость. Отдельную x64-сборку можно рассматривать только с проверкой 64-битного SDK и зависимостей.

## Что проверить после запуска

Подключение, прокрутку групп контакт-листа, изображения X-статусов, сообщения, получение аватаров BART и повторное подключение. Если обычная Windows использует 32-битную Miranda NG, ей также требуется 32-битная DLL.
