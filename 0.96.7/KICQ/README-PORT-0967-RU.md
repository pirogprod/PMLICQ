# PMLICQ — исходники для сборки с Miranda NG 0.96.7

Основа: последняя версия PMLICQ из диалога (`PMLICQ-BART-handshake-fix.zip`).
Это **адаптированная компоновка и проверка SDK**, а не подтверждённая Windows-сборка.

## Где брать 0.96.7

Официальный тег: https://github.com/miranda-ng/miranda-ng/tree/v0.96.7
Официальный исходный архив: https://sourceforge.net/projects/miranda-ng.mirror/files/v0.96.7/
Ревизия релиза: `ebe074e`. НЕ используйте заголовки из ветки development (0.96.8).

## Сборка

1. Скачайте или клонируйте исходники **Miranda NG v0.96.7**, включая зависимости, необходимые для её сборки.
2. Разместите каталог `KICQ` из этого архива в `<Miranda-source>/plugins/KICQ` (не переименовывайте каталог без корректировки путей).
3. Сгенерируйте решение штатным способом из исходников Miranda NG 0.96.7 и откройте его в Visual Studio.
4. Соберите цель `KICQ` для той же архитектуры (Win32/x64), что и ваша установленная Miranda NG 0.96.7.
5. Результат должен называться `PMLICQ.dll` (имя задано проектом); переносите его только в совместимую сборку клиента.

## Что проверено

- Официальные заголовки v0.96.7 содержат `USERINFOPAGE`, `PROTO_INTERFACE`, `PF4_AVATARS` и службы управления аватаром.
- CMake теперь проверяет релизный тег Miranda NG при конфигурации; явно неверный тег вызывает ошибку.
- Исходники остальной функциональности PMLICQ оставлены без изменений.
- Целостность архива и наличие файлов проверены.

## Что НЕ проверено

Полная компиляция MSVC, загрузка DLL в Miranda 0.96.7, получение/установка аватарок и передача файлов. Они по-прежнему могут иметь ошибки реализации; перенос SDK их не исправляет.

Примечание: файл `KICQ.vcxproj` из старых архивов использует общие props Miranda NG; предпочтителен проект, сгенерированный CMake для 0.96.7.
