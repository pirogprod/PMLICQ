PMLICQ — экспериментальный патч переключения статусов для Miranda NG 0.96.8

Основа: предыдущий архив presence-fix для 0.96.8.

Изменения:
- src/proto.cpp: только динамическое переключение статуса теперь использует flags=0 вместо 256, с диагностической записью.
- src/oscar.cpp: TLV 0x0006 сериализуется как одно 32-битное big-endian значение (байты эквивалентны прежним при тех же аргументах).
- Первоначальное подключение, подписка на контакты и keepalive НЕ менялись.

ВАЖНО: Это диагностическая гипотеза, а не подтвержденное исправление. Если разрыв сохранится, нужен свежий лог Open OSCAR Server, особенно OServiceSetUserInfoFields и сообщение OSCAR status switch.

Для 0.96.7: этот архив НЕ решает ABI-совместимость с Miranda 0.96.7. Собирать с соответствующими SDK/исходниками.

Имя выходного файла: PMLICQ.dll. Внутренний протокол: KICQ.
