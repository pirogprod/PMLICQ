# Аватары контактов — диагностика

Изменён только `KICQ/src/server.cpp`. Анкеты и передача файлов не менялись.

- Лог `BART: contact ... advertises avatar` — сервер прислал идентификатор изображения.
- `BART: queued image request` — запрос поставлен в очередь.
- `BART: authenticated service connection` — соединение с сервисом открыто.
- `BART: cached contact ... avatar` — файл получен и записан.
- `BART: image request failed` — сервер отверг запрос или прислал нераспознанный файл.
- `BART: disconnected ... pending ...` — запросы сохранены для следующего соединения, не потеряны.

Это исправление повторной очереди и диагностики. Оно не гарантирует, что AVS покажет картинку: для этого нужно дополнительно проверить интеграцию с интерфейсом аватаров Miranda NG на конкретной сборке.
