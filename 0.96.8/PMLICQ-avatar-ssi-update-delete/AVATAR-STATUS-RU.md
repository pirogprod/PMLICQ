# PMLICQ: обновление и удаление аватара (тестовая версия)

Реализована отправка SSI item type 0x14 для установки/обновления собственного значка; удаление отправляет SSI 13/0A с указанным item ID. Результат SSI 13/0E сопоставляется с номером запроса. После успеха установки BART upload 10/02 ставится в очередь; ответ 10/03 обрабатывается, локальный путь обновляется только после подтверждения сервера. Ответ 01/21 поддерживает повторное требование загрузки изображения.

Тесты: `g++ -std=c++17 tests/test_bart_ssi.cpp -o /tmp/test_bart_ssi && /tmp/test_bart_ssi` — пройдены.

Ограничения: сборка MSVC и реальный обмен с OSCAR-сервером НЕ проверены. Размер собственной картинки ограничен 8192 байтами. Кандидат SSI item ID 0x4000 может конфликтовать с уже существующим элементом на сервере; подтверждение сервера проверяется. Надёжная публикация при реконнектах, отражение изменений другим клиентам и полная совместимость остаются непроверенными. Остальные подсистемы не изменялись.
