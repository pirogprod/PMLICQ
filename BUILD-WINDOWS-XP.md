# Сборка PMLICQ для Windows XP SP3 (x86)

Ветка `PMLICQ-XP-BART-RECONNECT-FIX.zip` подтверждена пользователем как работающая на Windows XP x86, включая X-статусы и BART. Это не означает отдельной проверки обеих версий Miranda NG.

1. Используйте исходники Miranda NG той же версии, что выбрана в каталоге `windows-xp-x86/0.96.7/` или `windows-xp-x86/0.96.8/`.
2. Расположите проект внутри дерева сборки Miranda NG, сохранив вложенные каталоги исходников.
3. Откройте проект Visual Studio или добавьте его в решение Miranda NG.
4. Выберите **Release | Win32**, **Platform Toolset `v141_xp`** (Visual Studio 2019 с установленным XP-support).
5. Выполните Clean/Rebuild и найдите готовую `PMLICQ.dll`. Для PMLICQ внутренний проект по историческим причинам называется `KICQ`.
6. Проверьте, что сборка не содержит зависимостей `MSVCP140D.dll`, `VCRUNTIME140D.dll` и `ucrtbased.dll` (они обозначают Debug).
7. Сохраните копию прежней DLL и тестируйте на отдельном профиле Windows XP.

**Важно:** XP-совместимый toolset не гарантирует совместимости всех DLL-зависимостей, серверных функций и графических ресурсов.
