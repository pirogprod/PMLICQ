# PMLICQ ARS RX FIX5 — регистрация входящего файлового события

По Netlib Log от 08.11.2026 OSCAR-приглашения входящих файлов успешно распознаются (SNAC 04/07, CAP_FILE), но после каждого `incoming OSCAR file offer` следует `SQLITE error 19`.

В `HandleFileOffer()` добавлено `dbei.szModule = m_szModuleName` перед вызовом `ProtoChainRecvFile()`. В `RecvFile()` поле `szModule` устанавливается после сериализации `FILE_BLOB` перед `db_event_add()`. Добавлены сообщения `ARS RX FIX5` с результатом обработки.

Затронуты **только два участка кода входящих файлов в `proto.cpp`** каждого из 4 проектов. Отправка, ARS/OFT2-транспорт, контакты, статусы и остальные функции не изменены.

## Как проверять
1. Сохранить рабочие DLL и профиль. Собрать соответствующий проект 0.96.7 / 0.96.8 для Win32 или x64.
2. На другом клиенте отправить небольшой файл на PMLICQ.
3. Проверить, появился ли запрос, затем принять его и проверить фактическую передачу.
4. Если не появился, прислать Netlib Log со строками `ARS RX FIX5`, `SQLITE error`, `ARS DIAG3`.

Важно: эта правка устраняет обнаруженный риск некорректного DB-события, но не была собрана в Windows и не подтверждена сетевым тестированием. `SQLITE error 19` — класс ошибок ограничения SQLite; детали конкретного ограничения исходный лог не содержит.
