PMLICQ STABLE — порт исходников на Miranda NG 0.96.8
====================================================

x64_0.96.8/KICQ/    — перенесена стабильная x64 со сниженной нагрузкой при обновлении контактов.
x32_XP_0.96.8/KICQ/ — перенесена стабильная x86 с настройками v141_xp и WINVER/_WIN32_WINNT=0x0501.

За основу взят последний пользовательский стабильный архив для 0.96.7.
При переносе на API Miranda NG 0.96.8 сделано:
  * В src/proto.cpp создание контакта заменено на db_add_contact(m_szModuleName, flags)
    согласно исходникам ветки 0.96.8 из исходного архива.
  * В CMakeLists.txt ожидаемый тег изменён с v0.96.7 на v0.96.8.
  * В KICQ.vcxproj добавлено /utf-8, как в проекте 0.96.8.

Перенесены без функциональных изменений:
  * исходящая идентификация Miranda NG PMLICQ;
  * входящие отпечатки ICQ 5.1, ICQ 6, QIP 2012;
  * клиентские иконки и X-статусы;
  * текущий OSCAR-протокол, сообщения, BART/аватары, файлы;
  * x86-стабилизация и x64-оптимизация списка контактов.

ВНИМАНИЕ: это исходники, НЕ готовые DLL. Компиляция под SDK Miranda NG 0.96.8
и реальные тесты в Windows (включая Windows XP SP3 для x86) не проводились.
Настройки XP сохранены, но совместимость самого SDK/CRT 0.96.8 с XP
и наличие требуемых API нужно подтвердить сборкой и запуском.
Перед установкой сделайте резервную копию DLL и профиля Miranda.
