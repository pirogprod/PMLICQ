# Пакет исходников PMLICQ для GitHub — 21.11.2026

Это объединённый архив исходников PMLICQ для Miranda NG 0.96.7 и 0.96.8, x64 и Win32 (x86/XP).

Структура:

- `normal/0.96.7/KICQ/` — актуальная x64 0.96.7, оптимизированные обновления контактов;
- `normal/0.96.8/KICQ/` — порт актуальной x64 на 0.96.8;
- `windows-xp-x86/0.96.7/KICQ/` — стабильная по пользовательской проверке x86 0.96.7;
- `windows-xp-x86/0.96.8/KICQ/` — порт x86 на 0.96.8 с сохранёнными настройками сборки XP.

Документы верхнего уровня из первоначального пользовательского исходного архива скопированы без правок. В `README.md`, `CHANGELOG.md` и `GITHUB-UPDATE-RU.md` только добавлены новые разделы, исходный текст не удалялся и не переписывался. `README-PORT-0968-RU.txt` скопирован из последней версии порта без правок.

Подтверждения сборки/запуска всех четырёх целевых вариантов отсутствуют. Сторонние изображения имеют неизвестный/неподтверждённый лицензионный статус: для публичного репозитория необходимо удостовериться в праве их распространять.


## Дополнение 25.11.2026 — актуальное состояние

Этот исторический документ дополнен: текущий пакет основан на Avatar Beta 4 + x86 Presence Fix. Статус x86 в описании от 21.11 не переносится автоматически на новую сборку. Пользователь подтвердил стабильность x64; повторная проверка Win32 после исправления присутствия пока не сообщалась. Публикуются исходники, а не проверенные DLL. См. `RELEASE-PACKAGE-2026-11-25-RU.md`.
