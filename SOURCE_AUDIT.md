# Обзор исходников PMLICQ

**Область проверки:** загруженный архив `PMLICQ.zip`, содержащий два вложенных архива:

- `PMLICQ/PMLICQ-0.96.7.zip` — 92 файла (24 исходных файла/заголовка C/C++).
- `PMLICQ/PMLICQ-0.96.8.zip` — 105 файлов (30 исходных файлов/заголовков C/C++).

Проверка охватывала перечни файлов, заголовки с авторскими и лицензионными уведомлениями, метаданные проекта, сценарии сборки, определения ресурсов, точки входа API протокола и приложенную документацию разработки. Это **статический обзор**, а не сборка под Windows, аудит безопасности или проверка взаимодействия с реальным сервером.

### Результаты

1. Оба варианта представляют собой плагины PMLICQ на основе `KICQ`; в `version.h` прямо указаны Symnok и pirogprod.
2. Основные исходники плагина содержат уведомления о GPL версии 2 или любой более поздней; ни один из вложенных архивов не содержит отдельного полного текста лицензии.
3. В ресурсах присутствует графика QIP Infium; права на её повторное распространение не подтверждены. Это главное препятствие для публикации графики вместе с проектом.
4. Методы `SendFile`, `FileAllow`, `FileDeny`, `FileCancel` присутствуют в коде, но `GetCaps()` не объявляет `PF1_FILESEND` / `PF1_FILERECV`. В `OFT2-STATUS.md` прямо сказано, что сквозная передача файлов не проверена. Некоторые заметки разработки отстают от фактического состояния кода, поэтому README должен описывать возможности осторожно.
5. В варианте 0.96.7 в файле CMake есть явная проверка тега выпуска Miranda NG. Вариант 0.96.8 содержит дополнительные средства диагностики BART и аватаров.
6. Не путайте этот проект с PMLMRIM: предоставленный архив относится к PMLICQ / OSCAR, а не к MRIM.

**Рекомендуемая лицензия для кода:** `GPL-2.0-or-later` с сохранением всех исходных уведомлений. До публичного релиза следует урегулировать права на ресурсы и уточнить происхождение сторонних компонентов.

### Уточнение по ресурсам QIP Infium

Сопровождающий сообщает, что разработка исходного клиента QIP прекращена, а связаться с создателями графики не удаётся. Это сведения сопровождающего, а не подтверждение правового статуса. Происхождение оригинальных иконок отмечено в `THIRD_PARTY_NOTICES.md`; лицензия и разрешение на перераспространение остаются неустановленными.


### Обновление X-статусов Jimm Multi

В обычную ветку и XP-ветку (0.96.7/0.96.8) добавлен тестовый комплект 35 изображений X-статусов из `icq-xstatus.png` пользовательского JAR `Jimm_classic_zastavka (1)(1).jar`. Размер 16×16, XP-совместимые ICO, прежние имена и ID ресурсов. Исправлена отрисовка выпадающего списка с использованием `DrawIconEx`; «Дневник» скрыт только из интерфейса. Точечная логика обновления Extra Icons XP сохранена из успешно проверенного FIX3. Обычные редакции не проходили сборку/тест на Windows. Лицензия изображений не подтверждена.
