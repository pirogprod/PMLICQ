# Обзор этого архива

- Только одна **XP-совместимая линия** исходников PMLICQ.
- Два варианта по интерфейсам Miranda NG: `sources/0.96.7/` и `sources/0.96.8/`.
- Иконки X-статусов Jimm Multi (по 35 ICO на вариант), с исправленной прозрачностью; каталог статусов сохраняет внутренние GUID.
- Исправления Extra Icons и BART из XP-ветки сохранены.
- Целевая сборка Visual Studio 2019 `Release | Win32`, `v141_xp`; полная совместимость с Windows 7–11 и x64 не доказана.
- Набор содержит исходники; сквозное тестирование всех функций, включая OFT2, не проводилось.
