# PMLICQ — ICQ / OSCAR для Miranda NG (единая XP-11 совместимая ветка)

Неофициальный экспериментальный плагин классического протокола ICQ/OSCAR для **Miranda NG 0.96.7 и 0.96.8** https://github.com/miranda-ng/miranda-ng.

Проект основан на плагине KICQ.dll (от Symnok), с доработками pirogprod и других участников; сохраняйте авторские уведомления в исходниках. Для работы требуется совместимый сервер OSCAR.

## Структура и назначение

- `sources/0.96.7/KICQ/` — исходники под **Miranda NG 0.96.7**.
- `sources/0.96.8/PMLICQ-avatar-ssi-update-delete/KICQ/` — исходники под **Miranda NG 0.96.8**.
- `BUILD-VS2019.md` — инструкция сборки.
- `THIRD_PARTY_NOTICES.md`, `LICENSE-STATUS.md` — происхождение кода и ограничения на графику.

Это **одна XP-совместимая линия разработки с двумя вариантами SDK**, а не одна DLL, автоматически подходящая для двух версий Miranda NG. Не смешивайте заголовки/библиотеки 0.96.7 и 0.96.8.

## Поддерживаемая конфигурация сборки

Для сборки в **Visual Studio 2019** используйте `Release | Win32` и **`v141_xp`**. Цель — совместимость с 32-битной Windows XP SP3 и более новыми версиями Windows, включая 7/8/10/11. Плагин, собранный с XP toolset, **не становится автоматически совместимым со всеми ОС**: нужно проверить импорты DLL, CRT, SDK Miranda и поведение в системе. Для 64-битной Miranda требуется **отдельная x64 DLL**, и её поддержка/проверка данным архивом не подтверждена.

## Возможности

- Подключение к совместимым OSCAR-серверам, сообщения, контакты, авторизация, статусы.
- X-статусы, точечное обновление Extra Icons без массовых перерисовок контакт-листа.
- Набор из 35 иконок 16×16, подготовленный на основе ленты `icq-xstatus.png` из Jimm Multi (источник предоставлен сопровождающим).
- Получение/кеширование аватаров BART с доработками переподключения в XP-линии.
- Экспериментальная кодовая база передачи файлов OFT2 — работу между клиентами нельзя считать гарантированной.
