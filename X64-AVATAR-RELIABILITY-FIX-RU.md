# PMLICQ — x64: исправление нестабильного отображения аватаров

Область изменений: **только** `normal/0.96.7/KICQ/src` и
`normal/0.96.8/PMLICQ-avatar-ssi-update-delete/KICQ/src`.
`windows-xp-x86/` не изменялась; протокол обмена сообщениями, X-Status и передача файлов OFT2 также не затрагивались.

## Изменения

1. **Повторное подключение BART:** вторичный поток соединения BART теперь повторяет подключение примерно через 3 секунды, пока работает учётная запись. При остановке клиента он завершается.
2. **Повторный запрос при отсутствии кэша:** последнее объявленное сервером BART-ID записывается отдельно от ID реально загруженного аватара. Если файл изображения удалён, запрос повторяется при обращении к Avatar Service, не дожидаясь обновления онлайн-статуса.
3. **Ограниченные повторы при ошибке ответа:** при серверной ошибке или повреждённых данных запрос повторяется не более двух раз; бесконечный цикл исключён.
4. **Проверка кэша:** нулевой размер файла, каталог вместо файла и недоступный файл не считаются готовым аватаром.
5. **Смена аватара:** пока загружается новый ID, старый кэш не выдаётся за актуальный. Запоздавший ответ со старым ID не перезаписывает данные контакта.
6. **Оффлайн-кэш:** Avatar Service остаётся доступен для уже сохранённых изображений в оффлайн-режиме (`AF_ENABLED`).

## Проверка

На Linux локально прошли standalone-тесты кодеков BART, структуры SNAC/FLAP, серверных BART-фикстур, файлового кэша и BART roundtrip. Это **не является проверкой всей Windows DLL**: для неё нужен Miranda NG SDK соответствующей версии и Visual Studio x64, а для сетевой проверки — реальный OSCAR-сервер.

## Сборка

Используйте `Release | x64` из подходящего проекта:

- Miranda NG 0.96.7: `normal/0.96.7/KICQ/KICQ.vcxproj`;
- Miranda NG 0.96.8: `normal/0.96.8/PMLICQ-avatar-ssi-update-delete/KICQ/KICQ.vcxproj`.

Нужны исходники/SDK Miranda NG именно соответствующей версии. Из архива получается **исходный код**, а не готовый `PMLICQ.dll`. Сделайте резервную копию DLL и профиля до замены.

## Проверка после сборки

- Запустите Miranda x64, откройте контакт с аватаром и убедитесь, что он отображается.
- Удалите/переместите кэш изображения: клиент должен запросить его повторно после обращения Avatar Service.
- Поменяйте аватар на удалённом клиенте; старый не должен возвращаться после завершения нового запроса.
- Переподключите OSCAR или прервите вторичное BART-соединение: по журналу должна быть видна новая попытка.
- Проверьте аватары после перезапуска Miranda и в оффлайне, а также работу отправки/приёма файлов отдельно.

Для дальнейшего расследования пригодятся строки журнала `BART: queued`, `BART: disconnected`, `BART: image request failed`, `BART: cached and announced`.
