# PMLICQ: восстановление собственной аватарки и загрузка через BART

Источник для совместимости: присланный пользователем `bart.rs` (серверный обработчик OSCAR BART).

Изменения:
- Разбор SNAC(10,03): результат загрузки BART имеет размер 1 байт, не 2 байта.
- Чтение SSI-записи 0x0014, TLV 0x00D5 при получении и обновлении ростера.
- Запрос собственной старой аватарки по опубликованному MD5 через BART(10,06).
- Обработка BART(10,07) для собственного UIN и кэширование изображения для PS_GETMYAVATAR.
- Синхронизация кэшированного хеша и пути, сброс при удалении через SSI.
- Максимальный размер загружаемой картинки приведён к 7168 байтам (как на присланном сервере).
- Добавлен автономный тест tests/test_bart_server_compat.cpp.

Ни отправка файлов, ни анкеты, ни сообщения не менялись.

Ограничения: компиляция Visual Studio/MSVC и реальная работа с OSCAR-сервером НЕ проверялись. Если раньше собственная аватарка была опубликована в другом формате SSI или другим типом BART, потребуются дополнительные проверки сетевого лога. После сборки перезапустить Miranda и открыть «О пользователе → Аватар».
