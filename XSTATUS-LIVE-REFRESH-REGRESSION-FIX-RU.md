# FIX: Чужой X-статус не обновлялся до переподключения — 22.11.2026

## Подтверждённая причина

В четырёх ветках `server.cpp` после удаления собственных клиентских ExtraIcons осталось условие без тела:

```cpp
if (clientIconChanged)

if (xstatusChanged)
    KicqRefreshSingleXStatus(hContact);
```

В C++ это два вложенных условия: фактически `if (clientIconChanged && xstatusChanged)`. Во время установки или смены X-статуса уже определённого клиента `MirVer` не меняется, `clientIconChanged=false`, поэтому перерисовка не выполнялась. При переподключении `MirVer` мог переопределиться, и значок появлялся.

## Исправление

- Удалён зависший `if (clientIconChanged)` из обеих архитектур и версий.
- Удалён неиспользуемый `clientIconChanged` и присваивания из обработчика присутствия.
- Обновление значка при изменении X-статуса снова независимо от определения клиента:
  - x64: `if (xstatusChanged) KicqRefreshSingleXStatus(hContact);`
  - x86/XP: `if (xstatusChanged || presenceChanged) KicqRefreshSingleXStatus(hContact);`
- Не возвращены ExtraIcons клиентов; `MirVer` продолжает обрабатываться Fingerprint.
- Настройка собственного X-статуса и TLV 0x001D mood из предыдущей версии сохранены.
- Другие исходники, в т.ч. каталог определения клиентов, `proto.cpp` и сетевые пакетные функции, не менялись.

## Сверка с историческим релизом

`PMLICQ_0967_x64_DB_ABI_Fix_BETA3(1).zip` использует прямое условие `if (xstatusChanged) ExtraIcon_SetAll(hContact)` без зависимости от `MirVer`, что подтвердило регрессию в новой версии после удаления клиентских ExtraIcons.

## Проверка после сборки

1. Сохранить старую `PMLICQ.dll` и копию профиля Miranda.
2. Собрать соответствующую версию Miranda 0.96.7/0.96.8, x64/x86 из архива.
3. Войти через PMLICQ; проверить, что значок своего контакта остался.
4. На другом клиенте (ICQ/QIP/Jimm) установить, поменять, снять X-статус **без переподключения Miranda**.
5. Проверить обновление через секунды после серверного уведомления.
6. При отсутствии результата снять NetLog с SNAC `0x03/0x0B` и полями `0x000D`, `0x001D`: если сервер не отправляет событие, клиент не сможет обновить значок самостоятельно.

## Статус валидации

Проверена структура условий во всех четырёх исходных файлах и отсутствие изменения других исходников. DLL в Windows не собрана, реального сетевого тестирования пока не было. Этот пакет — исправление исходников, а не подтверждённый релиз DLL.
